## Features

### Rebuild extras (local fork on top of upstream v0.12.1)

- **Durable Runtime** — tool and model calls run on a two-phase commit ledger (register before execution, commit results) persisted to a SQLite event store; after a crash, restarts know exactly what did or did not run, side-effecting operations are never auto-replayed, and unknown outcomes are parked for user reconciliation. Includes parallel tool batches per model turn, persisted token usage, sensitive-field redaction, daily auto-backup, and atomic session persistence
- **Artifact Workbench** — agent outputs become first-class artifacts with a draft → review → submit → accept flow, revision-based optimistic concurrency, leases, in-app Univer spreadsheet editing (CAS revisions), and local Markdown previews for Office files via markitdown
- **Work Items & project management** — a unified durable task model powers kanban, calendar, list, and task-detail views, decoupled from sessions (sessions are optional execution links); calendar v2 with endTime/allDay/projectId; unified task/schedule editors
- **Theme engine rewrite** — semantic design tokens (depth/radius/border/density/icon stroke), OKLCH palette, live-reloading user themes, preferences unified in config.json, legacy theme.json migrated once; Windows native title-bar overlay blends with the theme; 14 bundled presets removed (user themes dir is now user-owned)
- **UI model v2** — multi-panel stacks replaced by Primary Surface + Context Workbench; session-list toggle moved to the top bar; Cmd/Ctrl+W layered close; sv=2 URL state; deep links for projects/automations; profile page gains a 52-week activity heatmap
- **Models & protocols** — OpenAI Responses protocol for custom endpoints; automatic model-list discovery (OpenAI/Anthropic/Ollama styles) with thinking-capability sync; 7 thinking levels incl. minimal; Moonshot AI / Minimax / Kimi (Coding) providers; ChatGPT search failover hardening; custom-endpoint credentials never sent to api.openai.com
- **Keyless multi-engine web search** — aggregates 10 engines (bing, duckduckgo, baidu, sogou, so360, brave, exa, startpage, csdn, juejin) with concurrent multi-engine queries and partial-failure reporting
- **Office tooling** — xlsx write-range/build (formulas, per-cell styles, conditional formatting, charts); pptx structured elements, lint (overflow/overlap detection) and SVG contact-sheet render; docx structured JSON documents (tables/images/page setup/headers-footers)
- **Runtime fixes** — sync_tools full toolset replacement, browser-tool toggle applies instantly, agent_settled turn-final event with authoritative context usage, recovery warnings injected into resumed sessions, Windows packaged search restored (ripgrep-win32), uv runtime PATH detection, report_progress tool, PowerShell tool on Windows

### Upstream v0.12.1

- **Moonshot AI (Kimi K3) support** — new connection presets for Moonshot AI (global and CN endpoints) with the full Kimi model family. Kimi K3 brings a 1M-token context window, always-on reasoning, and image input; Kimi K2.6 serves as the fast summarization model. The existing Kimi (Coding) preset gains the new `k3` model as well
- **Pi SDK updated to 0.81.1** — refreshed model catalogs across all Pi-backed providers, including the Kimi K3 thinking-format and reasoning-effort fixes

## Improvements

- ChatGPT web search failover is sturdier: model candidates are bounded, hosted-tool refusals are no longer mistaken for model rejections, and multi-attempt error messages stay readable
- GitHub Copilot sign-in re-enables policy-gated models (Claude, Grok, and others) from your account's live model listing, and the Copilot OAuth flows are now app-owned and hardened with network timeouts and standards-compliant polling
- Faster utility-model calls: the Pi model runtime is cached across summarization and title-generation requests instead of being rebuilt each time
- Settings now show proper provider labels for Minimax, Minimax (CN), and Kimi (Coding) connections instead of a generic backend label
- Kimi (Coding) connections pre-fill the current model lineup (`k3`, `kimi-for-coding`, `kimi-for-coding-highspeed`)

## Bug Fixes

- ChatGPT web search works again for ChatGPT-account connections — the search request no longer pins a retired model id and follows your active model instead. Fixes [#1023](https://github.com/craft-ai-agents/craft-agents-oss/issues/1023)
- Custom OpenAI-compatible endpoints no longer receive the unsupported `store` parameter, which broke strict providers. Fixes [#1022](https://github.com/craft-ai-agents/craft-agents-oss/issues/1022)
- WhatsApp: messages on LID-migrated accounts now resolve your own identity correctly, so self-sent messages and mentions behave again. Fixes [#1021](https://github.com/craft-ai-agents/craft-agents-oss/issues/1021)
