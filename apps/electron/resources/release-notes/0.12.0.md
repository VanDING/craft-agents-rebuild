## Features

- **New home at thecraftagents.com** — the app, downloads, auto-updates, shared session links, and documentation move to the new domain; existing share links and sign-in flows keep working during the transition (from upstream v0.12.0)
- **Docs access via the public docs site** — the built-in craft-agents-docs MCP source is gone; agents fetch setup guides from the docs site with their web tools, one less background connection per session (from upstream v0.12.0)
- **Trajectory panel** — a new timeline view of the session: request boundaries, deduplicated tags, resizable inspector, and system-prompt snapshots captured at each model turn, adapted for the deepseek harness
- **Workbench panels** — chat and file overlays now live as dockable panels bound to the active session: Context (workspace sources/skills plus session token usage, attachments, recent files, and source status), Files (with filename filter), Review & Diff, Preview, and Browser tabs; each panel expands to fullscreen in one click, panels equalize in width, and keyboard shortcuts switch between them
- **Session-list toggle** — a dedicated button keeps the session list visible while panels are focused
- **Kanban calendar views** — calendar day/week views over schedule entries, with close and fullscreen buttons on kanban and calendar headers
- **Pi SDK 0.84.2** — SDK-native OAuth for github-copilot, grok-x, and kimi-coding; the context window refreshes when you switch models; `browser_tool` is gated via the SDK `excludeTools` denylist; system prompts load through the public `resourceLoader` API
- **New connection templates** — grok-x, kimi-coding, openrouter, and radius; custom endpoint connections are named after the chosen model; internal Copilot model variants are filtered from the pickers
- **WeChat iLink inbound restored** — message classification, session expiry handling, and wire fields fixed; QR login retries automatically
- **Localization** — Claude-era onboarding copy replaced across 7 locales

## Improvements

- **Security hardening** — GitHub Actions pinned to commit SHAs; renderer CSP drops `unsafe-inline`/`unsafe-eval`; server-core sharp bumped to 0.35.3; beautiful-mermaid pinned
- **Leaner packaging** — the dormant session-mcp-server no longer ships; a stray 43 MB build artifact and Claude-era dead code were removed; four main-process build paths unified onto one script
- **Windows fixes** — POSIX fixtures resolve on Windows paths; backslash redirects are captured; quoted args survive `.cmd` wrappers; attachment filenames are basename'd, `~`-prefixed paths expand, and MCP command availability is preflighted

## Bug Fixes

- Trajectory panel — table width, tag dedup, compact timeline, scroll-ready gating, timeline legibility, request boundaries, inspector resize
- Panels — cross-workspace active-session leak fixed, ReviewPanel loading flash removed, dead atoms cleaned
- WeChat — iLink inbound delivery, API URL joining, QR login retries
- Transport — WebSocket message cap raised with client pre-flight
- i18n — locale files re-sorted so CI validation passes

## Breaking Changes

- **craft-agents-docs MCP removed** — the `SearchCraftAgents` tool and its built-in source are gone; agents fetch service-specific setup guides from the public docs site instead (from upstream v0.12.0)
