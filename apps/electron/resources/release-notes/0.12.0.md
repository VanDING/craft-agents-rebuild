## Features

- **Upstream v0.12.0 merged — new home at thecraftagents.com** — the app, downloads, auto-updates, shared session links, and documentation now live on the new domain; the app switches to the new update feed automatically, and existing share links and sign-in flows keep working during the transition
- **Built-in docs MCP removed** — agents now reference the product documentation via the public docs site instead of the bundled craft-agents-docs MCP source, one less background connection per session (from upstream v0.12.0)
- **100% DSH-parity trajectory rewrite** — trajectory data, logic, and UI rewritten for full parity with VanDSH: compact timeline, deduped tags, request boundaries, inspector resize, and a scroll-ready gate fix; system prompt snapshots are captured on SDK 0.84 `message_end`
- **Workbench panels** — chat/file overlays converge into bound panels: Context (workspace sources/skills + active session tokens, attachments, recent files, source status), Files (filename filter), Review & Diff, Preview, and Browser tabs; one-click fullscreen expansion, leftmost-eviction with main-session pinning at index 0, foreground limit + hidden panel set with LRU eviction, keyboard shortcuts, three-state flat buttons in the top bar, equalized widths, and narrow-panel adaptation
- **Independent session-list toggle** — a dedicated navigator button keeps the session list visible while panels are focused (decision #7)
- **Kanban calendar views** — Gantt view replaced with Calendar day/week views over standalone schedule entries; close + fullscreen buttons on kanban and calendar headers; matching time-grid row heights
- **Pi SDK upgraded to 0.84.2** — SDK-native OAuth for github-copilot, grok-x, and kimi-coding login and refresh; `contextWindow` refreshes on model changes via `set_model_result`; `browser_tool` gated through the SDK `excludeTools` denylist; system prompts use the public `resourceLoader` API instead of private-field stamping (fixes an ephemeral-prompt race)
- **New connection templates** — built-in templates for grok-x, kimi-coding, openrouter, and radius; custom endpoint connections are named after the chosen model; Copilot picker-marked models are filtered out, excluding internal variants
- **WeChat iLink inbound restored** — response classification, session expiry handling, and wire fields fixed; QR login refactored with retry/session handling
- **i18n** — Claude Agent SDK onboarding copy replaced across 7 locales

## Improvements

- **Packaging leaner** — session-mcp-server dropped from Docker and local staging (dormant); the 43 MB stray `main.cjs` artifact and orphan shared copies removed; four main-process build paths unified on `scripts/electron-build-main.ts` (single OAuth define source); Claude-era dead code purged (binary error helpers, 1M context pipeline, thinking-effort helpers, deprecated aliases)
- **Supply-chain hardening** — GitHub Actions pinned to commit SHAs (audit M-26); renderer CSP drops `unsafe-inline`/`unsafe-eval` (audit C-1 P1); server-core sharp bumped to 0.35.3; beautiful-mermaid pinned to ^1.1.3 (ui + session-tools-core were wildcard)
- **Windows fixes** — `getPathBasename` splits on both separators so POSIX fixtures resolve on Windows; backslash paths accepted in bash redirect capture; realpath check skipped for missing base dirs; quoted args preserved through `.cmd` wrappers; attachment filenames basename'd, `~`-prefixed portable paths expanded, MCP command availability preflighted

## Bug Fixes

- Trajectory layout — table width, tag dedup, compact timeline, table hidden by scroll-ready gate (craft layout adaptation), timeline legibility, request boundaries, inspector resize
- Panel audit — cross-workspace active-session leak, ReviewPanel loading flash, dead atoms; session list stays visible while bound panels are focused
- WeChat — iLink inbound delivery (response classification, session expiry, wire fields), API URL join fixed, QR login retries
- Transport — WS message cap raised with client pre-flight
- i18n — locale files re-sorted (chat.sessionFilesError was appended out of order; unblocks validate:ci)

## Breaking Changes

- **craft-agents-docs MCP removed** — the `SearchCraftAgents` tool, its built-in source, and its exemptions are gone; agents fetch service-specific setup guides from the public docs site instead (from upstream v0.12.0)
