## Features

- **Upstream v0.11.4 merged** — Claude Opus 4.6 is back as a selectable model (craft-agents-oss#1007): it appears again in the model pickers and Pi-backed catalogs, and connections that were previously force-migrated to Opus 4.8 get 4.6 re-added automatically (one-shot, your default model is left untouched). Opus 4.8 remains the default for new installs
- **Pi SDK upgraded to 0.84.0** — the unified backend (`@earendil-works/pi-coding-agent` / `pi-ai` / `pi-agent-core`) moves from 0.83.0 to 0.84.0, bringing:
  - Built-in **Baseten provider** (`BASETEN_API_KEY`, GLM-5.2 default)
  - Anthropic streams no longer drop text/thinking included in the initial content-block event
  - GitHub Copilot Grok 4.5 requests use the supported Responses API
  - OpenAI Codex WebSocket sessions are no longer shared across different account credentials
  - Fireworks GLM 5.2 requests stop sending the unsupported `prompt_cache_retention` field
  - Fixes for stalled OAuth refreshes, stale-credential sessions, and concurrent model-catalog refreshes
  - Security: undici 8.9.0 / brace-expansion 5.0.9 (multiple GHSA advisories)
- **What's New moved from the sidebar into Settings** — the release-notes panel now lives on the Settings page instead of a sidebar overlay

## Improvements

- **Faster packaging** — the DMG build no longer stages the removed Claude Agent SDK (~210 MB of native binaries and core copies), cutting a full x64 build from ~5 minutes to ~1.5 minutes; stale `index.js.fork` artifacts are purged from both the source and staged `dist/resources` so they no longer ship in the app
- **Server packaging fixed** — the WhatsApp worker build externals `sharp` (Baileys' runtime-optional native peer) instead of failing on its `.node` binaries; `bun run server:build` works again
- **Mirror-friendly downloads** — Bun runtime downloads honor `BUN_DOWNLOAD_BASE`, and the lockfile uses the npmmirror registry, for faster builds behind slow/unreachable GitHub connections

## Bug Fixes

- OAuth token refresh adapted to the Pi SDK 0.84 signal contract (`refresh(credential, signal)`); OpenRouter PKCE login passes the required interaction signal
- Explore mode no longer goes silent when a tool call is blocked — the agent sees the block reason again and can suggest switching modes or submit a plan instead of stopping without a word (from upstream v0.11.4)
